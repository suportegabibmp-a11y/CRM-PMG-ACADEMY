# CRM PMG - Sistema Moderno de Gestão de Relacionamento com Clientes

CRM completo para PMG com métricas avançadas, dashboard em tempo real e gestão de vendas.

## 🚀 Funcionalidades

- **Gestão de Clientes**: Cadastro completo com histórico de interações
- **Pipeline de Vendas**: Visualização do funil de vendas em tempo real
- **Métricas e Dashboard**: Gráficos interativos e KPIs importantes
- **Follow-up Automático**: Sistema de lembretes e acompanhamento
- **Gestão de Usuários**: Controle de acesso e permissões
- **Relatórios Detalhados**: Exportação de dados e análises

## 🛠️ Stack Tecnológico

### Frontend
- React 18 + TypeScript
- Tailwind CSS
- Chart.js / Recharts
- React Router
- Axios

### Backend
- Node.js + Express + TypeScript
- PostgreSQL
- Prisma ORM
- JWT Authentication
- bcrypt

## 📦 Instalação

```bash
# Instalar dependências de todos os projetos
npm run install:all

# Iniciar ambiente de desenvolvimento
npm run dev
```

## 📊 Métricas Principais

- Funil de vendas completo
- Taxa de conversão por etapa
- Tempo médio de resposta
- Valor médio de contrato
- Performance por vendedor
- Métricas em tempo real
